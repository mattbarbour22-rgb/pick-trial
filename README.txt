HOW TO OPEN THE LIVE PREVIEW

OPTION 1 — Open on your computer
1. Download the ZIP
2. Right-click the ZIP
3. Extract All
4. Open the folder
5. Double-click index.html

OPTION 2 — Put it live on Vercel
1. Unzip the folder
2. Upload the files to GitHub
3. In Vercel click:
   Add New Project
4. Select your GitHub repo
5. Click Deploy

Because this is plain HTML there is:
- no coding
- no build step
- no terminal
